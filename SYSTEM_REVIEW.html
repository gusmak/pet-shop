🔴 Vấn Đề Quan Trọng

1. Authentication chưa tồn tại — chỉ là mock
• Frontend: Đăng nhập ghi vào localStorage, không gọi API. Bất kỳ ai cũng có thể mở DevTools và set adminUser để bypass.
• Backend: Không có AuthModule, không JWT, không guard. Tất cả API endpoints đều public, không xác thực.
• Ảnh hưởng: Không thể deploy production. Dữ liệu admin hoàn toàn không được bảo vệ.
2. Frontend không kết nối Backend
• Form Đặt lịch: chỉ alert(), không gọi POST /api/bookings
• Form Liên hệ: chỉ alert(), không gọi POST /api/contact
• Trang Dịch vụ: dữ liệu hardcoded trong component, không fetch GET /api/services
• Admin pages: tất cả dữ liệu là useState([...]) hardcoded, không fetch API
3. Admin CRUD chưa functional
• Các nút "Thêm dịch vụ", "Sửa", "Xóa" chỉ là UI shell — không có logic xử lý
• Không có modal/dialog cho form create/edit
• Backend thiếu admin API endpoints (chỉ có read cho services, bookings)
4. Contact Service không lưu database
• contact.service.ts chỉ console.log() rồi return success
• Prisma schema thiếu model ContactSubmission (có trong schema.sql nhưng không sync)
• Mọi liên hệ khách hàng gửi sẽ bị mất

🟡 Vấn Đề Cần Lưu Ý

5. Prisma Schema ≠ SQL Schema
schema.sql có 15+ bảng (gallery, testimonials, blog_posts, contact_submissions...) nhưng Prisma schema chỉ có 12 models. Cần đồng bộ.
6. AdminJS Module vẫn còn trong Backend
admin.module.ts vẫn import AdminJS với hardcoded credentials. Đã chuyển sang custom admin panel trên frontend nhưng chưa gỡ code cũ. Có thể gây conflict và lộ credentials.
7. Số điện thoại không nhất quán
Sử dụng 0971 616 634 ở Header/Footer/ContactWidget nhưng 0912 345 678 ở trang Liên hệ và CTA sections. Cần thống nhất.
8. FRONTEND_URL sai port
.env backend: FRONTEND_URL=http://localhost:3000 nhưng frontend chạy port 3002. CORS sẽ block khi kết nối thật.
9. Google Maps embed URL là giả
GoogleMap.tsx dùng URL embed tĩnh với tọa độ giả (21.0050, 105.8250). Cần lấy embed thật từ Google Maps cho địa chỉ "7 Chùa Bộc, Đống Đa, Hà Nội".
10. Không có Tests
Backend có 2 file test mặc định NestJS (Hello World), frontend không có test nào. Chưa có unit test, integration test, hay e2e test thực sự.

📝 Kết Luận

Hệ thống PetShop đang ở giai đoạn prototype/MVP sớm. Phần UI frontend đã khá hoàn thiện với design đẹp và responsive tốt. Database schema được thiết kế bài bản. Tuy nhiên, phần kết nối giữa frontend và backend gần như chưa tồn tại — mọi form và trang admin đều dùng dữ liệu hardcoded.

3 việc cần làm ưu tiên cao nhất để có thể sử dụng thật:

  1. Kết nối Frontend ↔ Backend: Thay alert() bằng fetch API calls thật. Đưa dữ liệu services từ DB ra frontend. Xử lý form booking/contact qua API.
  2. Xây dựng Authentication: JWT auth module cho backend. Bảo vệ API endpoints. Thay mock localStorage bằng token-based auth thật.
  3. Admin CRUD API + UI: Backend endpoints cho admin operations. Modal forms cho create/edit. Dashboard stats từ database thật.
